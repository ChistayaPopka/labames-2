# Федор Лавшонок — личный сайт

Сайт-визитка студента ДВФУ и фруктовый автомат без денег и ставок.

- Главная: `/`
- Игра: `/play/`
- Next.js, TypeScript, Tailwind CSS 4, shadcn/ui (Base UI)

Запуск в PowerShell: `npm.cmd run dev`.
Статическая сборка: `npm.cmd run build`, результат в `out/`.
Проверка игровой логики: `node --experimental-strip-types tests/game.test.mjs`.

Результаты выбираются независимо в браузере через Web Crypto. Кнопка остановки завершает анимацию и показывает уже выбранную комбинацию. Основная кнопка явно запускает прокрутку, в том числе при системном уменьшении движения. Кнопка «Без анимации» выдаёт результат сразу. Декоративные анимации сайта по-прежнему учитывают `prefers-reduced-motion`. История последних пяти вращений хранится в памяти до ухода со страницы.
